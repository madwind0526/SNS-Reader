# UI Layout

## 기본 방향

- 좌측 아이콘 레일 중심의 최소 UI
- 메뉴: Obsidian DB 만들기, PDF 만들기, 설정
- 라이트/다크 모드 토글
- 사용자에게 보이는 텍스트는 한국어
- 긴 URL과 폴더 경로가 잘리지 않도록 입력칸은 넓게 배치

## Obsidian DB 만들기

화면 구성:

- 정리 대상 주소 입력
- 주요 SNS 계정 목록
- 계정 추가 버튼
- Obsidian 저장 폴더 입력
- 그림 저장 폴더 입력
- 포함 항목 체크박스
- Markdown 미리보기

필수 항목:

- 제목
- 날짜
- 본문

선택 항목:

- 댓글
- 그림
- 요약
- 태그

## PDF 만들기

화면 구성:

- Markdown 원본 폴더 입력
- PDF 저장 폴더 입력
- PDF 분할 기준 선택
- 포함 항목 선택
- 그림 표시 방식 선택
- 책 구성 미리보기

PDF 분할 기준:

- 년도별
- 날짜 기간별
- 페이지 수별

책 구성:

- 책 표지
- 책 내용 인포그래픽과 요약
- 각 게시글 페이지

## 설정

설정 화면은 1-5번 기본 입력값을 저장하는 장소입니다.

- 기본 정리 대상 주소
- SNS 계정 주소 목록
- 로그인 필요 여부
- 기본 Obsidian 폴더
- 기본 PDF 저장 폴더
- 기본 포함 항목
- 테마
