# Roadmap

## Wave 1: Project Scaffold

- 폴더 구조 생성
- Electron + React + TypeScript 기본 앱 생성
- Obsidian/PDF 메뉴 UI 초안 생성
- 설계 문서 작성
- git 초기화

## Wave 2: Settings Persistence

- 설정 저장/불러오기
- SNS 계정 추가/삭제 UI
- 폴더 선택 다이얼로그
- 테마 저장

## Wave 3: Obsidian Export MVP

- 수동 입력 또는 샘플 데이터 기반 Markdown 생성
- 게시글별 미디어 폴더 생성
- 콜라주 이미지 생성
- Markdown 미리보기

## Wave 4: Source Collectors

- Naver Blog 공개 글 수집
- X/Facebook/Instagram 접근 방식 조사 및 collector 분리
- 로그인 필요 플로우 설계

## Wave 5: PDF Export MVP

- Markdown 파서
- 책 단위 분할
- 표지/요약/본문 페이지 렌더링
- 각 글 새 페이지 시작 보장

## Wave 6: Packaging

- Windows 설치 파일 생성
- 설정 마이그레이션
- 오류 로그와 복구 화면
